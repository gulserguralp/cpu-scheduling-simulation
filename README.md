CPU Scheduling Algoritmaları Simülasyonu
Ödev Raporu

1. GİRİŞ
İşletim sistemlerinde kullanılan CPU zamanlama algoritmalarının çalışma mantığı incelenmiştir. 
Farklı zamanlama algoritmaları C++ programlama dili kullanılarak simüle edilmiştir.

2. KULLANILAN TEKNOLOJİLER
- Programlama Dili: C++
- Geliştirme Ortamı: Visual Studio Code
- Arayüz: Konsol

3. VERİ SETİ
Veriler CSV dosyasından okunmuştur. Dosya; Process_ID, Arrival_Time, CPU_Burst_Time ve Priority alanlarını içermektedir.

4. KULLANILAN ALGORİTMALAR
- FCFS
- SJF (Non-Preemptive)
- SJF (Preemptive)
- Priority (Non-Preemptive)
- Priority (Preemptive)
- Round Robin

5. HESAPLANAN DEĞERLER
Her algoritma için bekleme süresi, çevrim süresi ve bu değerlerin ortalamaları hesaplanmıştır.

6. SONUÇ
Algoritmaların performans farkları gözlemlenmiş ve CPU zamanlama mantığı daha iyi anlaşılmıştır.
